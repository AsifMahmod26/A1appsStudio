# A1AppsStudio website

Static, GitHub Pages–ready website for the A1AppsStudio Android development brand. The site uses plain HTML, CSS, and JavaScript and does not require a build step or package installation.

## Pages

- `index.html` — homepage
- `about.html` — studio information
- `applications.html` — application categories
- `games.html` — game categories
- `tools.html` — tools and utilities categories
- `privacy.html` — universal privacy framework and app-specific disclosure requirements
- `terms.html` — general website terms
- `contact.html` — contact guidance

## Before publishing

1. Add the verified developer contact email to the contact and privacy pages.
2. For each Android release, publish an app-specific privacy disclosure that accurately reflects that release’s data collection, sharing, permissions, SDKs, retention, and deletion behavior. Link it from that app’s store listing and in the app where appropriate.
3. Review the app’s store listing, privacy disclosures, and Data safety declarations together for consistency.
4. Publish the contents of this directory at the root of the configured GitHub Pages source.

No individual application or game release is named in this reusable site.
